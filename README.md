# Cognifyz Full Stack Development Internship - Task 1

## 📌 Project Overview

This project was developed as part of my **Cognifyz Full Stack Development Internship**.

Task 1 focuses on creating an HTML form and connecting it with a basic Node.js and Express server. The submitted form data is processed by the server and displayed dynamically using **EJS server-side rendering**.

## 🎯 Task Objective

The main objectives of this task are:

- Create a structured HTML form.
- Collect user information such as name and email.
- Create a basic server using Node.js and Express.
- Handle form submission using a POST request.
- Process submitted form data on the server.
- Use EJS for server-side rendering.
- Dynamically display the submitted information.

⚙️ How the Project Works

The application follows this flow:

User opens the form
        ↓
Enters name and email
        ↓
Clicks Submit
        ↓
POST request sent to Express server
        ↓
Express receives the form data
        ↓
EJS generates the response page
        ↓
Submitted information is displayed

🚀 How to Run the Project

1. Clone the repository
   
git clone https://github.com/shaikiman11/Cognifyz-Task1.git

2. Open the project folder
   
cd Cognifyz-Task1

3. Install dependencies
   
npm install

4. Start the server
   
node server.js

5. Open the application

Open the following URL in your browser:

http://localhost:3000
